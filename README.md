📊 Bank Transaction RFM Dashboard

## Overview
This repository contains an **Excel-based dashboard** built on **Bank Transaction RFM (Recency, Frequency, Monetary) analysis**.  
The project demonstrates how raw transaction data can be transformed into actionable insights for customer segmentation and business decision-making.

## ✨ Features
- **Data Cleaning & Transformation**  
  Standardized transaction records for consistency and accuracy.

- **RFM Analysis**  
  - **Recency**: How recently a customer has transacted.  
  - **Frequency**: How often they transact.  
  - **Monetary**: How much value they bring.  

- **Customer Segmentation**  
  Categorized customers into groups (e.g., High Value, At Risk, Lost) based on RFM scores.

- **Interactive Dashboard**  
  - Dynamic charts and slicers for filtering.  
  - KPIs for quick business insights.  
  - Visual storytelling of customer behavior.
